BANK ACCOUNT MANAGEMENT SYSTEM — DEMO

Files included:
- index.html: Interactive website demo for GitHub Pages.
- BankAccountManagement.cpp: Simple C++ OOP console-program example.
- README.txt: Instructions.

To publish on GitHub Pages:
1. Open your public GitHub repository.
2. Choose Add file > Upload files.
3. Upload index.html, BankAccountManagement.cpp and README.txt as individual files, not the ZIP file.
4. Click Commit changes.
5. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root). Save if settings changed.
6. Open the site link shown on the Pages settings page. It may take a few minutes.

Important: This is an educational demonstration, not a real banking service. Website demo records are saved only in the current browser using local storage. They are not shared with other visitors and are not connected to MySQL or a bank server. The C++ source file is a separate console-program example.
